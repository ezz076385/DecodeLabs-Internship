# Data Cleaning Project

## Overview
This project focuses on cleaning a raw dataset by identifying and handling common data quality issues. The goal is to prepare the dataset for analysis by ensuring accuracy, consistency, and completeness.

## Objectives
- Identify and handle missing or null values.
- Detect and remove duplicate records.
- Correct inconsistent or incorrect data formats.
- Prepare the dataset for further analysis and visualization.

## Dataset Issues Addressed

### 1. Missing Values
- Checked for null or empty cells.
- Applied appropriate handling techniques such as:
  - Removing rows with excessive missing data.
  - Filling missing values where suitable.

### 2. Duplicate Records
- Identified duplicate entries.
- Removed duplicate rows to improve data quality.

### 3. Data Format Corrections
- Standardized date formats.
- Corrected numerical data types.
- Cleaned and standardized text values.

## Tools Used
- Microsoft Excel
- Python (Optional)
  - Pandas
  - NumPy

## Skills Demonstrated
- Data Cleaning
- Data Preparation
- Data Quality Assessment
- Excel Operations
- Basic Python Data Processing

## Project Workflow

1. Load the raw dataset.
2. Inspect data structure and quality.
3. Handle missing values.
4. Remove duplicate records.
5. Correct data formats.
6. Validate the cleaned dataset.
7. Export the final cleaned dataset.

## Results
The cleaned dataset is:
- Free from duplicate records.
- Consistent in formatting.
- Improved in completeness and reliability.
- Ready for analysis and reporting.
