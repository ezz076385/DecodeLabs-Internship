# DecodeLabs Internship — Data Analytics
 
# DecodeLabs Data Analytics Projects

## Overview
This repository contains a collection of data analytics projects completed as part of the DecodeLabs training program.  
The projects cover data cleaning, exploratory data analysis, SQL querying, and data visualization.

Each project demonstrates core skills in data handling, analysis, and storytelling.

---

## Projects Included

# 1. Data Cleaning Project
### Goal
Clean raw data by handling missing values, duplicates, and incorrect formats.

### Key Tasks
- Identify missing/null values
- Remove duplicate records
- Fix incorrect data formats (dates, numbers, text)

### Skills Used
- Data Cleaning
- Excel / Python basics
- Data Preparation

📁 Folder: `01-Data-Cleaning`

---

# 2. Exploratory Data Analysis (EDA)
### Goal
Analyze data to understand patterns, trends, and distributions.

### Key Tasks
- Calculate mean, median, count
- Identify trends and patterns
- Detect outliers
- Summarize insights

### Skills Used
- Descriptive Statistics
- Data Analysis
- Analytical Thinking

📁 Folder: `02-EDA`

---

# 3. SQL Data Analysis
### Goal
Extract insights from data using SQL queries.

### Key Tasks
- SELECT queries
- WHERE filtering
- ORDER BY sorting
- GROUP BY aggregation
- COUNT, SUM, AVG functions

### Skills Used
- SQL Fundamentals
- Data Querying
- Filtering & Grouping

📁 Folder: `03-SQL-Analysis`

---

# 4. Data Visualization Project
### Goal
Create visual charts to communicate insights clearly.

### Key Tasks
- Create bar charts
- Create line charts
- Create pie charts
- Choose best visualization for data
- Highlight key insights

### Skills Used
- Data Visualization
- Storytelling with Data
- Chart Design

📁 Folder: `04-Data-Visualization`
